# QUINT v4.1 (Интеграция Hydra)

**QUINT** — это отказоустойчивый тактический протокол связи, разработанный для условий сильных помех (РЭБ), нулевой видимости или режима полной тишины.

## 1. Концепция и лицензия
* [cite_start]**Цель:** Надежная передача данных через визуальный, бинарный и тактильный слои[cite: 4].
* [cite_start]**Лицензия:** MIT[cite: 5].
* [cite_start]**Правило живучести:** «Правило одного тире» — если передача прервана, принимающая сторона должна принять значение «1» (максимальная опасность/вовлеченность)[cite: 6].

## 2. Базовая матрица (Пять узлов)
[cite_start]Протокол использует пять маркеров (узлов), каждый из которых имеет три уровня интенсивности[cite: 8].

| Узел (Маркер) | Значение 1 ( - ) | Значение 2 ( -- ) | Значение 3 ( --- ) |
| :--- | :--- | :--- | :--- |
| **N1: СТАТУС** | КОНТАКТ (Бой) | ТРЕВОГА | ТИШИНА |
| **N2: ДИСТАНЦИЯ** | РЯДОМ (0-30м) | БРОСОК | ДАЛЕКО |
| **N3: УГРОЗА** | ОГНЕСТРЕЛ | ХОЛОДНОЕ ОРУЖИЕ | ОГОНЬ / ВЗРЫВ |
| **N4: УРОВЕНЬ** | ВОВЛЕЧЕН | ОБНАРУЖЕН | НАБЛЮДАЮ |
| **N5: СЕКТОР** | ПЕРЕД СОБОЙ | ФЛАНГ | ТЫЛ |

## 3. Транспортные слои

### PULSE-QUINT (Бинарный слой)
[cite_start]Используется для передачи через свет, звук, вибрацию или давление[cite: 12].
* **Маркер (Точка `.`):** Короткий, резкий импульс. [cite_start]Количество точек указывает на **номер Узла**[cite: 13].
* [cite_start]**Данные (Тире `-`):** Отчетливо длинный импульс (примерно в 3 раза длиннее точки)[cite: 14]. [cite_start]Количество тире указывает на **Значение**[cite: 15].
* **Ритмические рекомендации:**
    * [cite_start]**Точка:** Мгновенное касание («тап»)[cite: 17].
    * [cite_start]**Тире:** Удержание («холд»)[cite: 18].
    * [cite_start]**Пауза внутри узла:** Короткий перерыв (равен одной точке)[cite: 19].
    * [cite_start]**Пауза между узлами:** Длинная пауза (явная тишина для отделения категории от данных)[cite: 20].
* [cite_start]**Пример:** `.. ---` (Узел 2, Значение 3) = **ДИСТАНЦИЯ: ДАЛЕКО**[cite: 21].

### VIS-QUINT (Визуальный/Тактильный слой)
[cite_start]Передача через удары ладонью по определенным зонам[cite: 23].
* [cite_start]**Высота (Узел):** Голова / Шлем (N1), Плечо (N2), Грудь (N3), Живот / Ремень (N4), Бедро (N5)[cite: 24].
* **Импульс (Значение):** Количество ударов в выбранную зону. [cite_start]Также допускается показ пальцами при условии хорошей видимости[cite: 25].

## 4. Операционные правила
* **Тройное резервирование:** Каждый пакет передается трижды. [cite_start]Пакет считается верным, если 2 из 3 итераций совпали[cite: 27].
* [cite_start]**Иерархия:** Бинарный импульс (Математика) > Жесты (Моторика) > Голос[cite: 28].
* [cite_start]**Приоритет Ноль:** Команда **CANCEL** (Отмена) немедленно сбрасывает текущую сессию по всем каналам[cite: 29].

## 5. Команды и заголовки
* [cite_start]**CANCEL (ОТМЕНА):** `... ... ...` (Три блока по три точки) или скрещенные руки («X»)[cite: 31].
* [cite_start]**INTERRUPT (ПРЕРЫВАНИЕ):** 5+ быстрых точек или жест рукопожатия[cite: 32].
* [cite_start]**COPY (ПРИНЯТО):** `.. .. ..` (Три блока по две точки)[cite: 33].
* [cite_start]**REPEAT (ПОВТОР):** `.... ....` (Два блока по четыре точки)[cite: 34].
* [cite_start]**ВЕДОМСТВЕННЫЕ ЗАГОЛОВКИ:** Опциональные префиксы для задания контекста[cite: 35].
    * **Полиция:** `. .. ...` (последовательность 1-2-3)[cite: 36].
    * [cite_start]**Медики:** `.. ... .` (последовательность 2-3-1)[cite: 37].
    * **Пожарные:** `... . [cite_start]..` (последовательность 3-1-2)[cite: 38].
* **SALAM (ПРИВЕТСТВИЕ):** Кулак к сердцу. [cite_start]Не тактический жест, используется для психологической связи («Я в порядке / Удачи»)[cite: 39].
