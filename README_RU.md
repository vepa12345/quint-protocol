# QUINT v4.1 (Интеграция Hydra)

**QUINT** — это отказоустойчивый тактический протокол связи, разработанный для условий сильных помех (РЭБ), нулевой видимости или режима полной тишины.

## 1. Концепция и лицензия
* **Цель:** Надежная передача данных через визуальный, бинарный и тактильный слои.
* **Лицензия:** MIT.
* **Правило живучести:** «Правило одного тире» — если передача прервана, принимающая сторона должна принять значение «1» (максимальная опасность/вовлеченность).

## 2. Базовая матрица (Пять узлов)
Протокол использует пять маркеров (узлов), каждый из которых имеет три уровня интенсивности.

| Узел (Маркер) | Значение 1 ( - ) | Значение 2 ( -- ) | Значение 3 ( --- ) |
| :--- | :--- | :--- | :--- |
| **N1: СТАТУС** | КОНТАКТ (Бой) | ТРЕВОГА | ТИШИНА |
| **N2: ДИСТАНЦИЯ** | РЯДОМ (0-30м) | БРОСОК | ДАЛЕКО |
| **N3: УГРОЗА** | ОГНЕСТРЕЛ | ХОЛОДНОЕ ОРУЖИЕ | ОГОНЬ / ВЗРЫВ |
| **N4: УРОВЕНЬ** | ВОВЛЕЧЕН | ОБНАРУЖЕН | НАБЛЮДАЮ |
| **N5: СЕКТОР** | ПЕРЕД СОБОЙ | ФЛАНГ | ТЫЛ |

## 3. Транспортные слои

### PULSE-QUINT (Бинарный слой)
Используется для передачи через свет, звук, вибрацию или давление.
* **Маркер (Точка `.`):** Короткий, резкий импульс. Количество точек указывает на **номер Узла**.
* **Данные (Тире `-`):** Отчетливо длинный импульс (примерно в 3 раза длиннее точки). Количество тире указывает на **Значение**.
* **Ритмические рекомендации:**
    * **Точка:** Мгновенное касание («тап»).
    * **Тире:** Удержание («холд».
    * **Пауза внутри узла:** Короткий перерыв (равен одной точке).
    * **Пауза между узлами:** Длинная пауза (явная тишина для отделения категории от данных).
* **Пример:** `.. ---` (Узел 2, Значение 3) = **ДИСТАНЦИЯ: ДАЛЕКО**.

### VIS-QUINT (Визуальный/Тактильный слой)
Передача через удары ладонью по определенным зонам.
* **Высота (Узел):** Голова / Шлем (N1), Плечо (N2), Грудь (N3), Живот / Ремень (N4), Бедро (N5).
* **Импульс (Значение):** Количество ударов в выбранную зону. Также допускается показ пальцами при условии хорошей видимости.

## 4. Операционные правила
* **Тройное резервирование:** Каждый пакет передается трижды. Пакет считается верным, если 2 из 3 итераций совпали.
* **Иерархия:** Бинарный импульс (Математика) > Жесты (Моторика) > Голос.
* **Приоритет Ноль:** Команда **CANCEL** (Отмена) немедленно сбрасывает текущую сессию по всем каналам.

## 5. Команды и заголовки
* **CANCEL (ОТМЕНА):** `... ... ...` (Три блока по три точки) или скрещенные руки («X»).
* **INTERRUPT (ПРЕРЫВАНИЕ):** 5+ быстрых точек или жест рукопожатия.
* **COPY (ПРИНЯТО):** `.. .. ..` (Три блока по две точки).
* **REPEAT (ПОВТОР):** `.... ....` (Два блока по четыре точки).
* **ВЕДОМСТВЕННЫЕ ЗАГОЛОВКИ:** Опциональные префиксы для задания контекста.
    * **Полиция:** `. .. ...` (последовательность 1-2-3).
    * **Медики:** `.. ... .` (последовательность 2-3-1).
    * **Пожарные:** `... . ..` (последовательность 3-1-2).
* **SALAM (ПРИВЕТСТВИЕ):** Кулак к сердцу. Не тактический жест, используется для психологической связи («Я в порядке / Удачи»).
