# QUINT v4.1 (multilayer protocol)

**QUINT** — это отказоустойчивый протокол связи, разработанный для **спасения жизней** в экстремальных условиях: при сильных помехах, нулевой видимости, в режиме тишины или при полном отказе радиосвязи.

## Назначение
Протокол предназначен для экстренных служб (парамедиков, пожарных, спасателей) как инструмент передачи критической информации в зонах ЧС, под завалами или при техногенных катастрофах, где важна каждая секунда.

## Ключевые принципы
* **Надежность:** Передача данных через визуальный, бинарный и тактильный слои.
* **Живучесть:** «Правило одного тире» — если передача прервана, принимающая сторона обязана принять значение «1» (максимальный приоритет/опасность).
* **Точность:** Тройное резервирование сообщений — пакет считается верным, если 2 из 3 итераций совпали.
* **Адаптивность:** Система ведомственных заголовков меняет контекст сообщения в зависимости от службы (Медики, Пожарные, Полиция).

## 1. Концепция и лицензия
* **Цель:** Надежная передача данных через визуальный, бинарный и тактильный слои.
* **Лицензия:** MIT.
* **Правило живучести:** «Правило одного тире» — если передача прервана, принимающая сторона должна принять значение «1» (максимальная опасность/вовлеченность).

## 2. Базовая матрица (5 узлов)
Система использует 5 зон (маркеров) или импульсов. Каждая категория имеет 3 уровня состояния.

| Узел (Зона) | Значение 1 | Значение 2 | Значение 3 |
|:---|:---|:---|:---|
| **PULSE** | `-` | `--` | `---` |
| **N1: СТАТУС** `.`| РАБОТА (На месте) | ВЫЗОВ (Тревога) | ОЖИДАНИЕ |
| **N2: ДИСТАНЦИЯ** `..`| ВПЛОТНУЮ (0-30м) | СРЕДНЯЯ | ДАЛЕКО |
| **N3: УГРОЗА** `...`| НУЖНА ПОМОЩЬ | ТРАВМА | ВЗРЫВ / ОГОНЬ |
| **N4: УРОВЕНЬ** `....`| ВОВЛЕЧЕН | ОБНАРУЖЕН | НАБЛЮДАЮ |
| **N5: СЕКТОР** `.....`| ПЕРЕД СОБОЙ | ФЛАНГ | ТЫЛ |

## 3. Транспортные слои
1. **PULSE-QUINT (Бинарный):** Передача через свет, звук, вибрацию или давление (точки и тире).
2. **VIS-QUINT (Тактильный):** Передача через похлопывания по зонам тела: Голова (N1), Плечо (N2), Грудь (N3), Живот (N4), Бедро (N5).

### PULSE-QUINT (Бинарный слой)
Используется для передачи через свет, звук, вибрацию или давление.
* **Маркер (Точка `.`):** Короткий, резкий импульс. Количество точек указывает на **номер Узла**.
* **Данные (Тире `-`):** Отчетливо длинный импульс (примерно в 3 раза длиннее точки). Количество тире указывает на **Значение**.
* **Ритмические рекомендации:**
    * **Точка:** Мгновенное касание («тап»).
    * **Тире:** Удержание («холд»).
    * **Пауза внутри узла:** Короткий перерыв (равен одной точке).
    * **Пауза между узлами:** Длинная пауза (явная тишина для отделения категории от данных).
* **Пример:** `.. ---` (Узел 2, Значение 3) = **ДИСТАНЦИЯ: ДАЛЕКО**.

### VIS-QUINT (Визуальный/Тактильный слой)
Передача через удары ладонью по определенным зонам.
* **Высота (Узел):** Голова / Шлем (N1), Плечо (N2), Грудь (N3), Живот / Ремень (N4), Бедро (N5).
* **Импульс (Значение):** Количество ударов в выбранную зону. Также допускается показ пальцами при условии хорошей видимости.

## 4. Операционные правила
* **Тройное резервирование:** Каждый пакет передается трижды. Пакет считается верным, если 2 из 3 итераций совпали.
* **Иерархия:** Бинарный импульс (Математика) > Жесты (Моторика) > Голос.
* **Приоритет Ноль:** Команда **CANCEL** (Отмена) немедленно сбрасывает текущую сессию по всем каналам.

## 5. Команды и заголовки
* **CANCEL (ОТМЕНА):** `... ... ...` (Три блока по три точки) или скрещенные руки («X»).
* **INTERRUPT (ПРЕРЫВАНИЕ):** 5+ быстрых точек или жест рукопожатия.
* **COPY (ПРИНЯТО):** `.. .. ..` (Три блока по две точки).
* **REPEAT (ПОВТОР):** `.... ....` (Два блока по четыре точки).
* **ВЕДОМСТВЕННЫЕ ЗАГОЛОВКИ:** Опциональные префиксы для задания контекста.
    * **Полиция:** `. .. ...` (последовательность 1-2-3).
    * **Медики:** `.. ... .` (последовательность 2-3-1).
    * **Пожарные:** `... . ..` (последовательность 3-1-2).
* **SALAM (ПРИВЕТСТВИЕ):** Кулак к сердцу. Не тактический жест, используется для психологической связи («Я в порядке / Удачи»).

## 6. Потоковая передача и наложение (Chaining)
Для описания сложных ситуаций используется метод последовательного суммирования признаков («плюсование»).

* **Механизм:** Узлы передаются один за другим с короткой паузой между ними.
* **Пример:** Нужно передать «Огневой контакт» (N1-V1) и «Нужен медик» (Заголовок Медика + N3-V1).
* **Логика наложения:** Если в одной зоне (например, Угроза N3) есть и огнестрел, и огонь, оператор передает Узел N3 со значением 1, делает паузу и снова передает Узел N3 со значением 3.
* **Завершение потока:** Любая многослойная передача должна заканчиваться сигналом **COPY** (`.. .. ..`), чтобы принимающая сторона знала, что перечисление окончено.
